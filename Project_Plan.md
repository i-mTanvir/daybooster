🔢 SCORING LOGIC SUMMARY
Binary tasks (Namaz, Meals, Journal):
  Done = 100% | Not Done = 0%

Minute tasks:
  % = (actual minutes ÷ target minutes) × 100
  Capped display at 200% max visual

Device Use (INVERSE):
  % = ((60 - actual minutes) ÷ 60) × 100
  Min 0%, Max 100%

Day Score:
  Average of all 17 task percentages

Weekly Score:
  Average of all 7 day scores

Vibe Character:
  Based on Weekly Score %
